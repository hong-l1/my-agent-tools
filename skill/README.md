# Skill：可复用的操作流程

一个 Skill 描述如何完成一类任务，包括触发条件、需要的上下文、执行步骤和完成标准。
它引用工具的能力与调用说明，不重复维护工具的实现代码。

每项流程遵循 [Agent Skills 规范](https://agentskills.io/specification)，使用独立目录，以 `SKILL.md` 保存元数据和指令，按需附带参考资料、模板或脚本。
指令和流程由 Agent 读取，与 Agent 使用 Go、Python 或其他语言实现无关。支持该格式的 Agent 复用同一份内容，安装位置和加载配置按宿主要求设置。

每项流程至少写清：

- **适用场景与边界**：何时使用，哪些任务不适用。
- **前置条件**：需要哪些输入、MCP Server、工具、配置和权限。
- **执行步骤**：操作顺序、分支条件和失败时的处理方式。
- **完成标准**：交付物是什么，如何验证结果。

使用相对路径；不要把账号、访问密钥、个人绝对路径或当前会话状态写入通用流程。
可共享的工具能力通过 MCP 调用，Skill 说明如何组织调用和判断结果。附带脚本时声明运行时和系统依赖，这些依赖与 Agent 自身的实现语言分开考虑。
