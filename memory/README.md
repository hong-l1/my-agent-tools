# Memory：可复用的上下文

这里承载需要跨任务保留的背景、偏好和项目决策。工具执行代码放在 `tools/`，通用操作流程放在 `skill/`。

## 存放约定

| 位置 | 用途 | 是否纳入 Git |
| --- | --- | --- |
| 本目录内经过审阅的文档 | 可共享的项目背景、模板和已确认决策 | 是 |
| `local/` | 个人偏好、私人项目上下文 | 否 |
| `runtime/` | 会话记录、临时状态和执行缓存 | 否 |

上述子目录按需创建。目前没有自动加载、同步或写回机制。

## 记录约定

- 标明适用范围、来源、更新时间和确认状态。
- 将事实、用户偏好、项目决策与待验证推断分开描述。
- 冲突记录需要核对来源；不根据单次会话自动覆盖长期偏好。
- 只保留需要复用的信息，不将所有日志直接当作长期记忆。
- 不记录密码、令牌和访问密钥。

接入 Agent 时，需要明确由谁选择和读取记忆，以及哪些更新需要用户确认。
